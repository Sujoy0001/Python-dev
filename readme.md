# Python Learning Workspace

This folder is used to learn new Python tools and store practice code for every new skill you try.

## Purpose

- Capture experiments with new libraries, frameworks, and tools
- Save code snippets and small projects as you learn
- Keep a personal learning history for future reference

## How to Use

- Add a new script or notebook each time you learn a new concept.
- Use descriptive file names to remember what you practiced.
- Keep notes in `readme.md` or nearby text files when needed.

## Example Topics

- Web scraping with `requests` and `BeautifulSoup`
- API automation and data collection
- Parsing HTML, JSON, and XML
- File handling, CSV, and JSON output
- Learning new Python libraries and development tools

## Notes

- This folder is for exploration and learning, not production code.
- Try new approaches, then keep the useful examples for later review.
- You can reuse this workspace as your personal Python practice area.
